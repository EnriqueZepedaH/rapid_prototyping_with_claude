# Latin Dance Chicago — Rapid Prototyping Project

## Overview
A rapid-prototyping project exploring 25 versions of a website about the best places to dance Latin rhythms in Chicago. The project tells the story of a design's evolution from initial exploration through combination and refinement.

## Tech Stack & Deployment
- **Pure HTML and CSS only** — no JavaScript, no frameworks, no build tools
- **Each version** is a single self-contained `.html` file with inline `<style>` CSS
- **Hosting:** Public GitHub repository
- **Deployment:** Free Vercel plan (static site)

## File Structure
```
├── CLAUDE.md       # This file — project plan & conventions
├── index.html      # Landing page / design gallery with links to all versions
├── v1.html         # Version 1
├── v2.html         # Version 2
├── ...
└── v25.html        # Version 25
```

## Content Requirements
Every version must include at minimum:
1. **Lessons** — Where to take Latin dance classes (salsa, bachata, cumbia, etc.)
2. **Socials** — Where to go out dancing (weekly socials, clubs, events)

Versions may add extra sections as the design evolves.

## Version Strategy
- **Phase 1 (v1–v10): Exploration** — Each version explores a different theme, style, or audience
- **Phase 2 (v11–v20): Combinations** — Combine best aspects from Phase 1 (based on user review)
- **Phase 3 (v21–v25): Refinements** — Polish the strongest combinations (based on user review)

### Phase 1 Themes
| Version | Theme |
|---------|-------|
| v1 | Clean & minimal |
| v2 | Bold & colorful — Latin-inspired palette |
| v3 | Dark/nightlife — club aesthetic |
| v4 | Beginner-friendly — approachable |
| v5 | Map/location-focused — by neighborhood |
| v6 | Event-calendar style — timeline layout |
| v7 | Magazine/editorial — large imagery |
| v8 | Social-media inspired — card-based |
| v9 | Community/forum — testimonials, profiles |
| v10 | Mobile-first design |

## Review Gates
- **STOP after Phase 1** — User reviews v1–v10 and decides what to combine
- **STOP after Phase 2** — User reviews v11–v20 and decides what to refine

## Landing Page
`index.html` serves as a design gallery telling the evolution story. Updated incrementally as versions are built.
